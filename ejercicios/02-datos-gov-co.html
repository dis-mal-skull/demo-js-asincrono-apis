La consulta

Socrata, en una URL

El dataset activo es 32sa-8pi3. El identificador anterior del material, xdk5-pm3f, ya no está disponible.

Endpoint GET

Orden descendente y límite de 800 filas.

Socrata
https://www.datos.gov.co/resource/32sa-8pi3.json?$order=vigenciadesde%20DESC&$limit=800

$order ordena por fecha descendente, $limit limita las filas y $where permitiría filtrar por rango. Los nombres con $ pertenecen a SoQL, el lenguaje de consulta de Socrata.

trm.js · normalizar y ordenar 
const filas = await respuesta.json();

// Normaliza, deduplica y ordena de más antiguo a más reciente
const porFecha = new Map();

for (const fila of filas) {
  const fecha = fila.vigenciadesde.slice(0, 10);
  const valor = Number(fila.valor);
  if (!fecha || !Number.isFinite(valor)) continue;
  porFecha.set(fecha, { fecha, valor });
}

const serie = [...porFecha.values()]
  .sort((a, b) => a.fecha.localeCompare(b.fecha));
