Cómo se construyó

Parámetros, conversión y dibujo

No hay librerías de gráficas: la sparkline es un path SVG construido con los precios de siete días.

coingecko.js · consulta de mercados 
const url = new URL("https://api.coingecko.com/api/v3/coins/markets");

url.searchParams.set("vs_currency", "usd");
url.searchParams.set("order", "market_cap_desc");
url.searchParams.set("per_page", "50");
url.searchParams.set("page", "1");
url.searchParams.set("sparkline", "true");
url.searchParams.set("price_change_percentage", "24h");

const { data } = await requestJSON(url, { timeout: 20000 });
sparkline.js · 46 puntos, área y línea 
function sparkline(precios, tendencia) {
  const puntos = downsample(precios, 46);
  const min = Math.min(...puntos);
  const max = Math.max(...puntos);
  const rango = max - min || 1;

  const coords = puntos.map((valor, i) => [
    (i / (puntos.length - 1)) * 300,
    46 - ((valor - min) / rango) * 40,
  ]);

  const linea = coords.map(([x, y]) => `${x},${y}`).join(" L");
  const area = `M${linea} L300,46 L0,46 Z`;

  return { linea, area, color: tendencia >= 0 ? "#0f8f78" : "#d64545" };
}

Decisiones clave

  • Token de cargaCada solicitud incrementa un contador; las respuestas viejas se descartan.
  • Caché por monedaLa clave es usd o eur; COP reutiliza USD y añade la tasa.
  • Respaldo coherenteSi se usa el JSON local, se fuerza USD y se avisa con un banner.
  • EscapadoTodo dato de API se inserta con textContent o nodos, nunca con HTML crudo.
¿Por qué convertir COP y no pedirlo a CoinGecko?

Porque el endpoint de mercados ya no admite cop como vs_currency. Se consulta en USD, se obtiene una tasa de cambio independiente y se multiplica en el cliente. Es una decisión documentada, no un parche invisible.

¿Cómo se maneja una imagen rota?

El img del logo escucha el evento error y se reemplaza por un círculo con las iniciales del símbolo. La demo nunca muestra el icono de imagen rota.
