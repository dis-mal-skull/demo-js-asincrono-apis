async function cargarPerfil() {
  const respuesta = await fetch(
    "https://jsonplaceholder.typicode.com/users/1"
  );

  if (!respuesta.ok) {
    throw new Error(`Error HTTP ${respuesta.status}`);
  }

  const perfil = await respuesta.json();
  pintarPerfil(perfil);
}

Puesta en marcha

Tres pasos y cero instalaciones

El proyecto solo necesita Node.js 18+ o PHP 8+. No hay npm install, bundler ni dependencias.

  1. 01

    Abre una terminal en la carpeta

    Entra a 01-demo, donde están index.html y server.js.

    cd 01-demo
  2. 02

    Inicia el servidor local

    Usa Node (npm start) o PHP (php -S localhost:5500).

    npm start
  3. 03

    Abre la dirección en el navegador

    Los módulos ES y fetch requieren un servidor HTTP, no file://.

    http://localhost:5500
No abras los HTML con doble clic

Con file:// el navegador bloquea los módulos ES, el JSON local y las peticiones al endpoint. Siempre usa el servidor.
