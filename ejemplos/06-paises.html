El código original

Así se consultaba la API

Este bloque conserva el ejemplo del material. Hoy la versión v3.1 responde con un error de deprecación, por eso el proyecto incluye un respaldo local con la misma estructura.

rest-countries.js · referencia histórica (v3.1) 
// Endpoint histórico, hoy retirado:
// https://restcountries.com/v3.1/all

fetch("https://restcountries.com/v3.1/all")
  .then((respuesta) => {
    if (!respuesta.ok) throw new Error("Error HTTP");
    return respuesta.json();
  })
  .then((paises) => {
    const colombia = paises.find((pais) => pais.cca3 === "COL");
    console.log(colombia.name.common);   // Colombia
    console.log(colombia.capital[0]);    // Bogotá
    console.log(colombia.currencies.COP); // peso colombiano
  })
  .catch((error) => console.error(error.message));

La estructura que conservamos

  • name.commonNombre visible del país.
  • capitalArreglo: un país puede tener varias.
  • currenciesObjeto por código ISO: nombre y símbolo.
  • languagesObjeto de códigos ISO a nombres.
  • timezonesArreglo de zonas horarias IANA.
Lección de resiliencia

Una API puede cambiar o desaparecer. Un respaldo local con el mismo contrato mantiene la demo educativa funcionando y permite comparar respuestas.
