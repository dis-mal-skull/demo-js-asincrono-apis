Anatomía de una petición

Cinco estados, un solo hilo

XHR es asíncrono por naturaleza, pero se controla con eventos. El código mostrado es el mismo que ejecuta esta página.

xhr.js · POST con FormData 
const xhr = new XMLHttpRequest();
const datos = new FormData(formulario);

xhr.open("POST", "../test.php", true);
xhr.timeout = 20000;

xhr.onreadystatechange = () => {
  if (xhr.readyState === 4) {
    console.log("Estado HTTP:", xhr.status);
    console.log(xhr.responseText);
  }
};

xhr.onerror = () => console.error("Fallo de red");
xhr.ontimeout = () => console.error("Tiempo agotado");

xhr.send(datos);
Estados de XMLHttpRequest
ValorConstanteSignificado
0UNSENTObjeto creado, sin abrir.
1OPENEDopen() ejecutado.
2HEADERS_RECEIVEDLlegaron las cabeceras.
3LOADINGEl cuerpo se está descargando.
4DONELa operación terminó.
Dato clave

readyState === 4 no garantiza éxito. Hay que revisar también que xhr.status esté entre 200 y 299.

¿Qué envía FormData exactamente?

Un cuerpo multipart/form-data con cada campo separado por un límite. El navegador genera ese límite y la cabecera Content-Type automáticamente: nunca la escribas a mano.
