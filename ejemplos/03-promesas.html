Cómo funciona

El valor llega cuando esté listo

La promesa representa el resultado futuro de una operación. El consumidor decide qué hacer con el éxito o con el error.

promesa.js · resolve / reject 
const numero = Math.floor(Math.random() * 10);

const promesa = new Promise((resolve, reject) => {
  setTimeout(() => {
    if (numero % 2 === 0) {
      resolve({ numero, mensaje: "Número par" });
    } else {
      reject(new Error("Número impar: " + numero));
    }
  }, 1200);
});

promesa
  .then((datos) => console.log("Resuelta:", datos))
  .catch((error) => console.error("Rechazada:", error.message))
  .finally(() => console.log("Siempre se ejecuta"));

Los tres estados

  • PendienteLa operación aún no produce valor ni error.
  • ResueltaEl valor está disponible y pasa al siguiente then.
  • RechazadaEl error viaja al catch más cercano.
No olvides el catch

Un rechazo sin manejar genera UnhandledPromiseRejection y puede detener la ejecución en Node.

¿then y catch devuelven la misma promesa?

No: devuelven una nueva promesa. Por eso se pueden encadenar transformaciones sin mutar la original. finally también devuelve una promesa y conserva el valor o el error.
